Dual-Agent Support

Technical and billing request routing with response sources.

A Java/Spring Boot backend separates technical and billing questions. The public demo uses rules and local documentation; OpenAI integration belongs to a separate CLI.

Try the applicationGitHub
Java 17Spring BootOpenAI API / CLIJUnitMavenDocker / Linux ARM64

Implementation

  • TECH/BILLING routing, session context and responses with documentation sources and executed tools.
  • The multi-turn refund collects an email, reason and optional date, validates them and creates a sample case identifier.
  • The REST API handles chat, reset and health. Sessions expire after 30 idle minutes and allow 30 turns.

Verification

Tests cover response sources, billing, refunds, reset, session isolation and invalid dates. Public HTTPS scenarios work on desktop and mobile.

Limitations

The public version makes no LLM or semantic RAG calls and mainly matches English keywords. Prices and refunds are samples; no email or money is sent. Restarting clears conversations. The paid OpenAI API was not tested live during the audit.
