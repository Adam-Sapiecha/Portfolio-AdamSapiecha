Pipelines and results

Jenkins pipelines

I build and maintain CI/CD pipelines that connect Python tools with operations on computers and boards. They cover device preparation, firmware flashing, test execution and passing results to the reporting system.

Data processing and dashboards

I develop Python tools that retrieve and parse Jenkins results and prepare data for database storage. I contribute to dashboards with run details, statistics and charts that developers use to investigate issues.

Working with embedded devices

Connecting hardware to automation

As a team, we develop the communication layer between Python tools and physical devices. It supports commands, power control and remote firmware flashing. Jenkins integration allows the complete workflow to run across multiple computers and boards.

Linux diagnostics

I configure connections, inspect processes and logs, and diagnose issues encountered when working with physical boards. I trace interactions between Python tools, the operating system and hardware to identify the source of a failure.

Outcomes

The system is used by Samsung R&D developers working on SoC platforms. Automation reduces manual device preparation and test execution, while results are available in a shared web application.
