Context and purpose

The foundation organized examinations for children in schools. Results handling involved manually reviewing and sorting documents, assigning them to the right recipients and organizing delivery.

My task was to turn that workflow into a working system. I integrated the platform with the foundation’s existing website and built a mobile application providing access to results and electronic payments.

From examination records to user access

  1. 01 · Input

    Examination data and results enter the digital platform handled by the Python/FastAPI backend.

  2. 02 · Processing

    The backend parses and sorts results, automates account creation and assigns documents to the right people.

  3. 03 · Storage

    Data and results are stored in GCP infrastructure integrated with the rest of the system.

  4. 04 · Access

    Users receive electronic access to results through the platform or the Flutter application.

What I designed and delivered

Requirements and architecture

I worked directly with the client, analyzed existing processes and designed data flows between the website, backend, mobile application and cloud services.

Python and FastAPI backend

I implemented data-processing logic, APIs and backend integration with the existing website and mobile application.

Results and account automation

I built result parsing, sorting and recipient-assignment mechanisms, automated account creation and electronic document delivery.

Flutter mobile application

I built an application for accessing examination results and payments, connecting it with the Python/FastAPI backend and GCP and Firebase services.

Cloud integrations and payments

GCP provided the main system infrastructure. I integrated Firebase, AWS email services and Stripe for electronic payments.

Deployment and maintenance

I delivered the system to production, working on input validation, error handling, troubleshooting and data migration to the Medfile cloud.

Outcomes and adoption

The platform and application were used by several thousand users across multiple schools. In the workflow I implemented, electronic access replaced paper-based result delivery.

Automated account creation, sorting and result distribution reduced administrative work, shortened processing and reduced users’ wait for results.

Correct result assignment

The system handled children’s examination results. Matching documents with the correct recipients and maintaining a consistent data flow were important requirements throughout the design.
