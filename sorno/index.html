I independently designed and deployed an examination-results platform and a Flutter mobile app. I handled the full process, from defining requirements with the client to implementation, production deployment and maintenance. The solution served several thousand users across multiple schools.

My work Outcomes

What I designed and deployed

Requirements, architecture and backend

I worked with the client to review the existing results-handling workflow and define requirements. I designed data flows between the existing website, backend, mobile app and cloud services, then implemented APIs and data-processing logic in Python and FastAPI.

Automating result delivery

I built mechanisms for parsing and sorting results, assigning them to recipients, creating accounts automatically and delivering documents electronically. Because the system handled children’s examination results, matching each document to the correct recipient was a key design requirement.

Mobile app and integrations

I built a Flutter app for viewing examination results and making payments, and connected it to the backend. The system ran primarily on GCP. I integrated Firebase, AWS email services and Stripe for electronic payments.

Deployment and maintenance

I deployed the solution to production and maintained it, working on data validation, error handling and troubleshooting. I also worked on data migration to the Medfile cloud.

Outcomes

Within this workflow, electronic access to results fully replaced paper-based delivery. Automating account creation, document sorting and distribution reduced administrative work and users’ wait for results.
